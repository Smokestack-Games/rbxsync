# File Formats

RbxSync represents a Roblox game on disk with two things: **scripts as plain
`.luau` files** and **a single context file, `datamodel.rbxjson`**, that holds
the rest of the instance tree.

## Overview

| What | Where it lives | Source of truth |
|------|----------------|-----------------|
| Script source | `.luau` files under `src/` | The files — edit them and sync to Studio |
| Everything else (parts, models, UI, folders, properties) | `datamodel.rbxjson` at the project root | Studio — RbxSync regenerates the file |

## Script Files

Scripts are stored as plain `.luau` files. The filename suffix determines the
script class:

```
MyScript.server.luau  → Script (runs on server)
MyScript.client.luau  → LocalScript (runs on client)
MyScript.luau         → ModuleScript
```

The `.luau` file is the editable source of truth for a script's code. Editing it
and running `rbxsync sync` pushes the change to Studio.

See [Scripts on Disk](/file-formats/luau) for details.

## The Context File

`datamodel.rbxjson` is a single nested JSON document that mirrors the entire
instance tree. Every instance is a node with its `className`, `name`,
`properties`, and nested `children`. Scripts appear as nodes too, but their
`Source` is stripped and replaced by a `sourcePath` pointer to the `.luau` file
on disk.

```json
{
  "className": "DataModel",
  "name": "DataModel",
  "children": [
    {
      "className": "Workspace",
      "name": "Workspace",
      "children": [
        {
          "className": "Part",
          "name": "Baseplate",
          "properties": {
            "Anchored": { "type": "bool", "value": true },
            "Size": { "type": "Vector3", "value": { "x": 512, "y": 20, "z": 512 } }
          }
        }
      ]
    }
  ]
}
```

RbxSync generates and maintains `datamodel.rbxjson`; treat it as read-only. It is
the context RbxSync gives AI assistants and the Luau language server so they can
see the whole game without every instance being its own file. Hand-editing it
does **not** push non-script changes to Studio — the sync-to-Studio path reads
scripts only. To change a non-script instance, edit it in Studio; the change
flows back into the context file.

See [The Context File](/file-formats/rbxjson) for the full document format and
[Property Types](/file-formats/property-types) for how individual property
values are encoded.

## Project Structure

```
MyGame/
├── rbxsync.json          # Project configuration
├── datamodel.rbxjson     # Full instance tree (generated by RbxSync)
├── src/                  # Scripts on disk
│   ├── ServerScriptService/
│   │   └── Main.server.luau
│   ├── ReplicatedStorage/
│   │   └── Modules/
│   │       └── Utils.luau
│   └── StarterPlayer/
│       └── StarterPlayerScripts/
│           └── Client.client.luau
├── assets/               # Binary assets (meshes, images, sounds)
└── terrain/              # Terrain voxel data
```

Directories under `src/` mirror the DataModel path of the scripts they hold.
Services and containers that hold no scripts don't appear under `src/` — they
live in `datamodel.rbxjson`.
